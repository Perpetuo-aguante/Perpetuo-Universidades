# Perpetuo para universidades

Sales room del piloto gratuito de un año para universidades. Se manda a cada universidad con quien hablamos.

La llamada se agenda con el enlace de Apollo del botón "Agendar llamada" (sección 05).

## Archivos
- `index.html`: toda la página (HTML, CSS y JS en un solo archivo, sin compilación). Mismo sistema visual que `mesa-ia-literatura` y `escribe-con-nosotros`.
- `assets/logo.webp` y `assets/partes/`: logo y muñecos del brandbook (copiados de `mesa-ia-literatura`).
- `assets/img/`: ilustraciones sacadas del press kit.
- `CNAME`: `universidades.perpetuo.global` para GitHub Pages.

## Liga personalizada
Agrega `?u=` con el nombre de la universidad y la portada cambia:

    https://universidades.perpetuo.global/?u=UNAM

Cambia el saludo ("…a UNAM."), la etiqueta ("Propuesta para UNAM"), el título de la pestaña y el asunto del correo.

## Secciones
1. La propuesta (el piloto)
2. Por qué Perpetuo
3. Qué van a leer
4. Cómo funciona
5. Siguiente paso (contacto)

Las cifras están en la lista `.cifras` al inicio del `<main>`.
